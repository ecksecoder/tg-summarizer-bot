## Ключевые возможности

### Кросс-языковой интеллект (Сквозной перевод и суммаризация)
AI Context Hub функционирует как универсальная система сквозного кросс-языкового синтеза. Любые входящие материалы — интернет-ссылки и веб-статьи, документы PDF, файлы DOCX, исходный код и текст TXT, а также аудиозаписи и голосовые сообщения — на любых иностранных языках (английском, немецком, французском, китайском, японском и др.) автоматически анализируются, полностью переводятся и оформляются в виде структурированной выжимки непосредственно на рабочем языке интерфейса пользователя (русском, украинском или английском). Все заголовки, ключевые тезисы, аргументы и практические рекомендации адаптируются на целевой язык с точным сохранением числовых метрик, параметров и терминологии.

### Мультиформатный конвейер извлечения данных
- Документы и исходный код: Высокопроизводительный локальный парсинг бинарных файлов (PDF через `pypdf`, DOCX через `python-docx`) и широкого спектра текстовых данных (`.txt`, `.md`, `.py`, `.csv`, `.log`, `.json`, `.ini`, `.cfg`, `.gsc`) объемом до 20 МБ без сторонних облачных посредников.
- Аудио и голосовые сообщения: Эфемерная обработка аудиозаписей (`.mp3`, `.ogg`) и голосовых заметок Telegram через Google GenAI File API с последующим немедленным удалением временных файлов с удаленного сервера сразу после генерации выжимки.
- Веб-контент (`parser.py`): Локальная асинхронная загрузка страниц с помощью `aiohttp` со стандартными заголовками браузера, проверка сетевой безопасности anti-SSRF (блокировка приватных, loopback, link-local и служебных IP-подсетей), очистка элементов разметки (`script`, `style`, `nav`, `header`, `footer`) библиотекой `BeautifulSoup` и жесткое усечение объема до 20 000 символов для защиты контекстного окна LLM.

### Многоуровневые форматы выжимок
Материалы формируются в трех фиксированных уровнях сжатия, настраиваемых по умолчанию или переключаемых в один клик через интерактивные inline-кнопки:
- SHORT (Шпаргалка): Предельно плотная сводка из 5–7 важнейших фактов, цифр и метрик, оптимизированная для просмотра на одном экране мобильного устройства.
- MEDIUM (Конспект): Сбалансированный структурированный конспект из 8–12 логически сгруппированных пунктов с сохранением контекста, аргументации и практических выводов.
- LONG (Пересказ): Детальный хронологический и тематический разбор материала с исчерпывающим изложением методологии, технических нюансов и рекомендаций.

### Асинхронный приоритетный обработчик очереди и изоляция локали
Все поступающие материалы помещаются в изолированную оперативную очередь FIFO с разделением приоритетов:
- Приоритет 1: Текстовые заметки и файлы в формате простого текста.
- Приоритет 2: Структурированные бинарные документы (PDF, DOCX).
- Приоритет 3: Веб-ссылки.
- Приоритет 4: Голосовые сообщения и аудиофайлы.

Фоновый воркер обрабатывает задачи последовательно для каждого пользователя, исключая скачки лимитов TPM (Tokens Per Minute) и RPM. Перед стартом каждой задачи воркер считывает актуальный язык пользователя из SQLite, обеспечивая строгую изоляцию локали при параллельных операциях.

### Трехъязычный интерфейс с автоопределением и переключением на лету
- Шлюз онбординга: Новые пользователи без сохраненного языка в базе данных при первом вызове команды `/start` видят интерактивную inline-клавиатуру для выбора английского (`en`), украинского (`uk`), русского (`ru`) или автоматического определения по Telegram-клиенту (`auto`).
- Динамический режим Авто: Выбор опции Авто динамически определяет язык клиента Telegram пользователя, сохраняя NULL в базе данных для бесшовной адаптации на разных устройствах.
- Переключение в рантайме: Пользователь может в любой момент изменить язык через команду `/lang` или кнопку меню (`btn_lang`). Настройки немедленно сохраняются в SQLite, а маркеры inline-кнопок и постоянная клавиатура ReplyKeyboardMarkup перерисовываются на лету.
- Надежность фильтрации: Обработчики сообщений aiogram используют генератор вариантов текста (`get_button_variants`) для предотвращения пропусков команд во всех языковых комбинациях.

### Автоматические миграции SQLite
- Режим Write-Ahead Logging (WAL): Конкурентные обращения к базе данных выполняются в отдельном пуле потоков через неблокирующую асинхронную обертку.
- Идемпотентные миграции схемы: Автоматическая проверка и создание недостающих колонок (`language` в таблице `user_settings`, `raw_text` и `format_size` в таблице `summaries`) при старте без внешних миграционных утилит.
- Очистка скользящего окна: Механизм скользящего окна (`SLIDING_WINDOW_RAW_LIMIT`) автоматически удаляет исходный несжатый текст старых материалов, сохраняя сами выжимки и защищая базу данных от избыточного роста.

## Технический стек

| Компонент | Технология | Назначение |
|---|---|---|
| Среда выполнения | Python 3.10+ | Асинхронная среда выполнения |
| Фреймворк | aiogram 3.x | Маршрутизация Telegram Bot API, контекст FSM, inline- и reply-клавиатуры |
| Основной инференс | Google GenAI SDK | Round-robin ротация ключей API по моделям Gemini Flash |
| Резервный инференс | Groq Cloud SDK / REST | Аварийный переход на llama-3.3-70b-versatile при исчерпании квот |
| База данных | SQLite 3 (режим WAL) | Хранилище с высокой параллельностью и поддержкой внешних ключей |
| Парсинг веб-страниц | aiohttp + BeautifulSoup4 | Асинхронная загрузка по HTTP, валидация anti-SSRF, очистка DOM |
| Парсинг документов | pypdf, python-docx | Извлечение текста из файлов PDF и DOCX |
| Конфигурация | python-dotenv | Чтение и валидация переменных окружения |

## Установка и настройка окружения

### 1. Клонирование репозитория
```bash
git clone https://github.com/your-username/ai-context-hub.git
cd ai-context-hub
```

### 2. Настройка виртуального окружения

На Linux / macOS:
```bash
python3 -m venv venv
source venv/bin/activate
```

На Windows (PowerShell):
```powershell
python -m venv venv
venv\Scripts\Activate.ps1
```

### 3. Установка зависимостей
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Настройка переменных окружения
Скопируйте `.env.example` в `.env`:

На Linux / macOS:
```bash
cp .env.example .env
```

На Windows (CMD):
```cmd
copy .env.example .env
```

Определите следующие переменные окружения в файле `.env`:

| Переменная | Обязательна | Описание |
|---|---|---|
| `BOT_TOKEN` | Да | Токен аутентификации Telegram Bot API, полученный от BotFather. |
| `GEMINI_API_KEYS` | Да | Список ключей Google Gemini API через запятую для round-robin ротации. |
| `GROQ_API_KEY` | Нет | Ключ Groq Cloud API, используемый как аварийный шлюз при исчерпании квот Gemini. |
| `ALLOWED_USER_IDS` | Нет | Список числовых идентификаторов пользователей Telegram через запятую. Если пуст, доступ не ограничен. |
| `SLIDING_WINDOW_RAW_LIMIT` | Нет | Максимальное количество сохраняемых исходных текстов на пользователя (по умолчанию: 10). |

Пример конфигурации `.env`:
```ini
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrSTUvwxYZ
GEMINI_API_KEYS=AIzaSyA1...,AIzaSyB2...,AIzaSyC3...
GROQ_API_KEY=gsk_your_groq_key_here
ALLOWED_USER_IDS=123456789,987654321
SLIDING_WINDOW_RAW_LIMIT=10
```

### 5. Запуск приложения
```bash
python bot.py
```
